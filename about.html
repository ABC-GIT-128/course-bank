关于 OpenCourse

把老师发的期末复习资料，整理成能刷、能订正、能查漏的网页题库。

这是什么

一个纯静态的课程题库站点：没有账号、没有后台、不收集任何个人信息。所有答题记录只存在你自己的浏览器里，换设备就是新进度。你可以导出进度，在另一台设备导入。

内容从哪里来

  • 自编题：依据课程复习要点重新命题、自己撰写解析，独创性属于贡献者。
  • 改写题：保留原题考点，重写题干表述与选项。
  • 已授权材料：资料提供者明确同意公网使用，授权记录留存在项目的 consent/ 目录。

每题都带「出处」字段，能看到它来自哪份资料。我们不收录：完整试卷原卷与标准答案、含学生姓名学号的任何材料、学校明令保密的文件。

许可

  • 代码：MIT，见 LICENSE，可自由使用、修改、再分发。
  • 题目与解析：CC BY-NC-SA 4.0（署名—非商业性使用—相同方式共享），见 LICENSE-content。
  • 本许可不覆盖任何第三方课件、教材、试卷内容。这些内容的版权归原作者，本站仅作学习参考与考点整理。

内容保留多久

只保留最近两个学年的课程。超出窗口的课程会移入「往期课程」归档区，仍可查看，但页面会提示可能与本学期考纲不一致。 更早的内容会从站点移除，避免学生按过期资料复习。

下架与纠错

本站为学习者自发整理，非任何学校官方发布，也不代表授课教师的意见。如果某份内容侵犯了你的权利，或你不希望它被公开：

  • 在项目仓库提一个 下架申请，写明课程名与题目编号；
  • 不方便用 GitHub 的话，让任意一位同学转告维护者也可以；
  • 我们承诺 72 小时内下架相关内容并回复。

下架后该内容不再出现在任何页面；如需恢复，可由维护者操作。所有下架记录（时间、范围、原因）都会留档备查。

我要贡献

不需要写代码。推荐先到 批量整理页：把题目整段粘进去，页面会实时检查格式并预览，确认无误再提交，能省掉来回改。

四步提交：

  1. 打开 批量整理页，点「填入示例」看格式，然后换成你自己的题目；
  2. 页面若提示某题格式不对，按提示改（比如答案要写成 A/B/C/D、填空的空位数要和答案组数一致）；
  3. 点「去投稿」，把内容粘进 GitHub 表单（首次需要登录一次 GitHub 账号），勾选两个确认后提交；
  4. 维护者核对后打上 approved 标签，系统自动生成 PR 并合入，题目署上你的名字。

只想交一两道题也可以，直接填「新增题目」表单，一栏一个字段，不用记格式。

没有 GitHub 账号也没关系：在班级群里填收集表，由维护者代录，同样署名；也可以直接在 仓库 Issue 区留言。

审核标准只有三条：答案正确、解析讲得清、出处可查。涉及版权存疑的一律退回。

为什么投稿要审核：公开站点一旦被塞进错误答案或侵权内容，先受影响的是照着背的同学。审核权始终由人掌握，机器只负责把表格转成数据。

手上是一整份文档怎么办？

文档不要上传到本站或公开仓库。课件、复习要点、试卷里常带老师姓名、学校模板、教材插图，有些还夹着学生名单；一旦提交到公开仓库，即使之后删掉，历史记录和别人的 fork 里仍然留着，收不回来。

所以这里分成两条通道：

你手上是怎么交之后会发生什么
一两道题 用上面的表单直接填 审核通过后自动入库，署你的名
一整份文档
（十几道题以上）		 私聊维护者 / 班级群发文件；
或按 批量模板（CSV） 整理好再发		 维护者整理后批量入库，文档本身不进公开仓库

把文档发来之前，请先删掉学生名单、学号、成绩这类内容。原始资料只在维护者本地存档，站点上只出现整理后的题目。

隐私

本站不使用 Cookie 追踪，不接入第三方统计，不做用户画像。答题进度保存在浏览器 localStorage 中，清除浏览器数据即消失。页面不收集、不上传任何个人数据。

页面可以「添加到主屏幕」，装好后会缓存页面文件，断网也能打开；缓存里只有网页和题库数据，不含任何个人信息。
