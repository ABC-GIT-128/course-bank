Q2单项选择第1章PPT 专节
“并不是所有的传感器都必须包含敏感元件和转换元件”，这一说法（　）。
PPT出处：《第1-10章课堂课件》 第一章 传感器的组成
A正确
B错误
正确答案
A. 正确
解析

许多传感器把敏感元件与转换元件合二为一（如压电晶片既感受力又直接输出电荷、热电偶既是敏感元件又是转换元件），因此不能说“必须都有”。这也是课上的一道判断题。

A非电量信号
B电量信号
C位移信号
D光信号
正确答案
B. 电量信号
解析

被测量可以是物理量、化学量、生物量，但输出量要便于传输、转换、处理、显示，因此主要是电物理量（电压、电流、频率、电荷、电阻、电容等）。

B63.2%

解析

一阶系统单位阶跃响应：τ → 63.2%、延迟时间 td → 50%、上升时间 tr → 90%。τ 越小，响应越快、频率特性越好。

Q17单项选择第3章PPT 专节
恒流源电桥的主要特点是（　）。

Q18单项选择第4章PPT 专节

A成正比

Q19单项选择第4章PPT 专节
电感式传感器的主要缺点是（　）。

A结构复杂、可靠性差

Q21单项选择第5章PPT 专节
一般变极距型电容传感器，极板间距通常取在（　）范围内。
PPT出处：《第1-10章课堂课件》 第五章 变极距型电容传感器
A2.5~20nm
B25~200μm
C1~5mm
D10~50cm
正确答案
B. 25~200μm
解析

起始电容一般 20~100pF，极板间距 25~200μm，最大位移应小于间距的 1/10，否则非线性误差过大、且易击穿。故变极距型最宜测微小位移。

Q22单项选择第5章PPT 专节
“变面积型电容传感器不管是直线位移式还是角位移式，其灵敏度系数都与初始电容成正比”，这一说法（　）。
PPT出处：《第1-10章课堂课件》 第五章 变面积型电容传感器
A正确
B错误
正确答案
A. 正确
解析

变面积型 ΔC/C₀ = Δx/b（或 Δθ/θ），绝对灵敏度 ΔC/Δx = C₀/b，确实与初始电容 C₀ 成正比；这也是提高初始电容可提高灵敏度的依据。

Q23单项选择第5章PPT 专节
当变间隙（变极距）型电容传感器的初始间距 d₀ 增加时，将引起（　）。
PPT出处：《第1-10章课堂课件》 第五章 变极距型灵敏度
A灵敏度增加
B灵敏度减小
C非线性误差增加
D非线性误差不变
正确答案
B. 灵敏度减小
解析

灵敏度 ≈ εS/d₀²，d₀ 增大则灵敏度减小；同时相对非线性误差 (Δd/d₀) 反而减小（线性变好）。这正是“灵敏度与线性度相互矛盾”的体现。

Q29单项选择第6章PPT 专节

B错误

B. 错误

Q66计算题第2章PPT 专节
某温度传感器测量范围为 −20～+100℃，在 50℃ 处误差最大，为 −3℃。求该传感器的精度（精确度）等级值，用百分数表示。
PPT出处：《第1-10章课堂课件》 第二章 2.2 精度；课堂练习
只需填写数值（单位 %），允许 4% 误差
正确答案
2.5%
解析

精度（精确度）用“最大绝对误差 ÷ 满量程 × 100%”表示，注意分母是量程跨度（120℃）而不是上限 100℃——这是最常见的失分点。

解题步骤
① 满量程：YFS = 100 − (−20) = 120 ℃
② 最大绝对误差：Δmax = 3 ℃
③ 精度 = Δmax / YFS × 100% = 3/120 × 100% = 2.5%
Q67计算题第3章PPT 专节
100Ω 的应变片在外力作用下（应变 ε = 0.005），电阻变化了 1Ω。求该应变片的灵敏系数 K。
PPT出处：《第1-10章课堂课件》 第三章 应变片灵敏系数
只需填写数值，允许 3% 误差
正确答案
K = 2
解析

K 的定义就是“单位应变引起的相对电阻变化”：K = (ΔR/R)/ε。金属应变片 K ≈ 1+2μ ≈ 2，与本题结果吻合。

解题步骤
① ΔR/R = 1/100 = 0.01
② K = (ΔR/R)/ε = 0.01/0.005 = 2
Q68计算题第2章PPT 专节
某传感器为一阶系统，受阶跃输入作用时：t = 0 时输出 10mV，t = 5s 时输出 50mV，t → ∞ 时输出 100mV。求该传感器的时间常数 τ（单位 s）。
PPT出处：《第1-10章课堂课件》 第二章 一阶传感器例题
只需填写数值（单位 s），允许 5% 误差
正确答案
τ ≈ 8.5 s
解析

一阶系统阶跃响应是指数趋近过程：经过 τ 完成总变化量的 63.2%。本题用“任意两点代入求 τ”的方法，先算增量再代指数式，注意要用增量而不是绝对输出值。

解题步骤
① 阶跃响应：y(t) = y∞ − (y∞ − y0)·e^(−t/τ)，其中 y0 = 10mV，y∞ = 100mV
② 稳态增量 = 100 − 10 = 90mV；t = 5s 时已变化 50 − 10 = 40mV
③ 40 = 90(1 − e^(−5/τ)) ⇒ e^(−5/τ) = 50/90 = 0.5556
④ −5/τ = ln0.5556 = −0.5878 ⇒ τ ≈ 8.5 s
Q69计算题第9章PPT 专节
直射式光电转速传感器的开孔圆盘上有 N = 60 个孔，测得光敏元件输出脉冲频率 f = 3000 Hz。求转速 n（单位 r/min）。
PPT出处：《第1-10章课堂课件》 第九章 直射式光电转速传感器
只需填写数值（单位 r/min），允许 3% 误差
正确答案
3000 r/min
解析

光电转速传感器靠“遮光—透光”产生脉冲，n = f/N（N 为孔数）。与霍尔/电涡流测速 n = N脉冲/(z·t) 是同一个思路，只是这里给的是频率，不必再除时间。

解题步骤
① 圆盘每转一圈输出 N 个脉冲，故 n = f / N = 3000/60 = 50 r/s
② 换算：50 r/s × 60 = 3000 r/min
