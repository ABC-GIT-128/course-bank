## 四、每道题的字段

```js
{
  id: 'k01',              // 稳定编号，用于纠错与定位
  doc: 'paper-a1',        // 指向 course.sources 里的资料
  type: 'calc',           // 六类之一
  ch: 2,                  // 章节号
  q: '题干…',
  // —— 按题型不同 ——
  opts / ans,             // 单选
  blanks,                 // 填空（每组可含同义写法）
  kw,                     // 名词解释（关键词组）
  ansText, points,        // 简答 / 综合（参考答案 + 要点）
  value / unit / tol,     // 计算（数值 + 单位 + 容差）
  sol,                    // 计算步骤
  // —— 通用 ——
  exp: '详细解析…',        // 为什么对、易错点、相关结论
  ref: '《A卷·第一套》五、1' // 出处，精确到题号
}
```

页面上每道题下方显示的是「资料名 + 章节」，解析里显示的是 `ref` 的精确出处。

## 七、自评题的判分口径

简答与综合题不自动判分，因为主观表述无法用关键词可靠覆盖。流程是：

1. 在文本框写下要点 → 点「提交答案」；
2. 自动展开参考答案、要点标签与解析；
3. 用户对照后点「我答对了」或「没答对」；
4. 选「没答对」会进错题本，可重练。

进度统计把这两类算作已答，正确率按自评结果计。
